## 1.3.0 - 2026-10-29

- Added dedicated "Smooth Z Speed" interactive UI tab inside OrcaSlicer to configure Simple vs Advanced settings with modern controls and live Gaussian curve visualizer.
- Shared persistent configuration synchronized between the UI tab and the slicing pipeline.
- High-res edge-to-edge icon optimized for OrcaCloud.

## 1.2.0 - 2026-10-29

- Added Simple and Advanced modes. Simple mode provides 1:1 behavior with Bambu Studio and Creality Print (zero configuration needed). Advanced mode unlocks fine-tuning for Gaussian radius, kernel window, stop threshold, and gradient ramp mode. Platform-suffixed wheels added for full OrcaCloud cross-platform compatibility.

## 1.1.0 - 2026-10-29

- Initial OrcaCloud release. Brings continuous Z outer wall speed smoothing to OrcaSlicer using the 1:1 Bambu Studio and Creality Print iterative Gaussian relaxation algorithm. Eliminates horizontal speed banding and gloss mismatches on sensitive filaments like Silk PLA, PETG, and ABS. Runs cross-platform via OrcaSlicer's native Python slicing-pipeline architecture.
